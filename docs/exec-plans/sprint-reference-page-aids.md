# 原片参考标注页省力辅助（reference-page-aids，2026-10-27第五会话）

所属阶段：Phase 0验收第2步（事前查询与原片参考，主查询≥10个独立可用参考；看板第3节、human-inputs“新来源的事前查询与原片参考”）。选题：本会话离线候选排名工作流（3视角侦察9候选＋3评委打分）第一名，8.05/10（安全分最低8）。不改冻结／验收合同，不代填人工判断，不花钱。

## 一、对用户来说多了什么

用户确定素材分组后最费力的一步，是逐个主查询看原片、登记至少10个独立可用事件。新生成的标注页增加：

1. 主查询进度“已登记 x/10 个真实事件，还差 y 个”（只计数，独立性仍由人判断）；
2. 视频下方“已登记区间条”：本原片上所有查询已登记的区间（当前查询彩色、其他查询灰色），时钟核对通过后点击跳到起点；
3. 新区间与本查询中另一个事件名称的区间重叠时先提醒、不登记，原样再点一次才登记（同一个动作重复命名会在冻结和评分时造成重复）；
4. 键盘：I／O标记起止（复用按钮上的全部原片时钟保护）、逗号／句号约一帧步进、[ ]调速0.25×–2×；在输入框中打字不触发。

## 二、合同

- 标注记录格式、`RECORD_VERSION`、`contextSha256`、模板、`validate()`与旧记录载入全部不变；只改页面脚本、页面HTML与样式。
- 键盘标记只能通过已有的“用当前位置标记”按钮路径（`SourceClock.captureSourceUs`及寻址／readyState／时长复核）；时钟未核对时只提示原因。
- 区间条跳转只在时钟核对通过时用`SourceClock.sourceUsToPlayerSeconds`换算；未通过时色块禁用。

## 五、评估结果

三视角（原片时钟与人工标注／记录合同与状态／体验回归）评审工作流：三方均**PASS**，无P0／P1，因此无需反驳核实。10个P2（部分重复）处理：
- 播放速度标签改由播放器`ratechange`驱动，并设`defaultPlaybackRate`，切换查询（重新载入原片）后速度与标签一致；浏览器原生菜单调速也能同步；
- 重叠确认键包含被重叠事件及其区间，且在修改起止／事件名、删除参考、载入记录后清空，避免旧确认放过新的冲突；
- 勾选复选框或使用文件框后快捷键仍可用（只有文字输入框屏蔽快捷键）；
- 区间色块不再是Tab停留点；当前查询色块画在最上层；区间条与播放器同宽（640px，窄屏随宽度缩小），与播放器进度条对齐；
- 少例显示“须1–9个”，0个或超过9个时提示冻结会拒绝。
