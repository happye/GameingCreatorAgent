# P020：活动规则解析（离线）

2026-11-01，Claude Code主控实现，gc-reviewer独立评估。

## 合同

- application/activity_rules.py：纯函数提取名称/时间/平台/最短最长时长/方向/话题/禁止项；每个值带原文行号与原句；不明确的为None。
- infrastructure/rule_sources.py：txt/md（UTF-8/GB18030）、html（标准库解析，去script/style）、图片（Windows OCR）、PDF（Windows.Data.Pdf渲染≤10页后OCR）；单次临时目录用后删除；≤10MB。
- POST /api/creation/activity-rules：{text}或{fileName,dataBase64}，仅该路径放宽请求体至约14MB；错误返回中文说明。
- 页面：解析结果带〔第N行〕引用；“填入需求”只填可直接映射的字段，禁止事项与方向留给人工。
