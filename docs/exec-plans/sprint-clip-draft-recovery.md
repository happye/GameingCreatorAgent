- dirty 恢复取消不变；确认恢复可一步撤销，旧 overlay 异步失效。显式丢弃只删当前 key；成功保存清父 key，失败保存保留。卸载不清除。
- 去抖幂等写；异步 hash 以 scope/epoch 防旧写；存储失败保留输入和旧存储并提示。
