# 录像和事前查询可以用表单登记

现在不用手写最初的计划JSON，就能登记本地录像、同源录制组、开发／测试用途及事前玩法查询。没有填完也能保存草稿，下次载入继续；导出计划前必须明确用途、是否看过模型结果，以及每个查询对应哪段录像。未知项保持未知，不从文件名或数量猜独立性。

改录像编号会保持对应查询的关联；录像还有查询时会提示先调整，避免误删。载入错文件、重复字段或载入期间的新编辑会保护当前登记。已有人工参考／版本／填写人／复核的计划拒绝登记导入，回原片标注页继续，不悄悄清掉判断。

使用的是单独生成的本机表单，当前不在8765工作台菜单。步骤见[登记指南](../references/benchmark-plan-editor-guide.md)，本机开发演示在artifacts/benchmark-plan-editor-validation/登记 表单/edit.html。演示带三段已有开发来源和事前查询，明确保留“已看过结果”，不能当独立测试。
