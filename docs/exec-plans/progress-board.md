## 7. 维护规则（所有 Agent 必须遵守）

1. **每次重大改动后立即更新本看板**：功能状态、F006 步骤、待办数量、技术债计数、“正在做 / 下一步”，并改“最后更新”行。与 `HANDOFF.md`、当前 sprint、`progress.md`、`assignments.md`、`human-inputs.md`、`tech-debt.md` 在同一次提交内对齐。
2. 数字必须可核对：功能数按 `feature_list.json` 的 `passes`；技术债按 `tech-debt.md` 表格状态列；待办按 `human-inputs.md`“仍待”表格。不能估算，不能把“工具就绪”写成“验收通过”。
3. 重大改动指：功能或流程变化、验收/门槛相关修复、费用或模型行为变化、阶段/里程碑状态变化、新增或解决技术债、新增或完成人工待办。
4. 任务开始时先读本看板第 6 节；结束或交接前更新第 6 节。子 Agent 把结果交给主控，由主控更新看板。
