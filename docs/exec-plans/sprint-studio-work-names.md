# Studio 作品命名

P032 / P039 · J1 第五次反馈 · 2026-11-20

剪辑区的「当前作品」选中已有作品后，可以修改并保存「作品名称」。新建作品后也可命名。下拉列表使用已保存名称，旧作品在首次命名前仍显示创建时间。

名称单独写入作品的本机元数据，按项目和作品核对，整份记录有版本和哈希。保存使用原子替换。已有作品记录、预算归属和剪辑版本保持原有身份。旧草稿无显式作品 ID 时仍按原路径打开。

## 验证

- 用 [漫画群星 60 秒已存剪辑版本](http://127.0.0.1:8765/studio?project=artifacts%2Fdemo-phase0&job=d4ed99deee984284b7178ee20b240085)打开实际作品。临时调整镜头速度后命名，未保存状态和速度仍保留。空白浏览器再次打开时读到「漫画群星 1V1 与 3V3 · 60 秒玩法展示」以及原有版本。比对作品与剪辑回执文件，哈希一致。
- 空名称在浏览器提示。跨项目写入被拒绝。定向测试覆盖同 ID 创建重试、受损名称元数据回退和作品身份保持。真实浏览器记录在 `.cache/scratch/narration-captions-20261120/name-trial-work.log`。

名称已在剪辑区可见。素材和发布区按作品归组仍待接入，J1 观感与可发布性仍待真人复测。
