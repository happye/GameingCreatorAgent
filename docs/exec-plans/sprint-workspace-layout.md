## 用户反馈与实施范围

原页面把语义时间轴放在全页下方，预览和片段篮随页面滚出，增加反复操作。本轮保留已有 DOM 身份和功能，改为桌面固定视口：左侧项目素材；中央上方视频监看和证据，下方语义时间轴；右侧上方自然语言检索，下方独立片段篮。列表分别滚动，导出固定在篮子底部。1366×768 和 1440×900 为必验视口。

设计使用深蓝中性色、克制蓝色强调、统一间距和控件尺度。标题栏保留后续编排/成片工作流的明确「待开放」位置；侧边栏为模板/音乐/平台预设预留静态资源区域，不提供虚假功能。小屏按正常纵向阅读排列，390px 不应出现横向溢出。

root 同时实施片段篮时间排序和 JS 重绘滚动保持；候选仍保持相关性排名。布局不改变 F006 人工检索质量标准。
