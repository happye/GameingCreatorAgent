# 本机旁白字幕随音轨移动

R2 · P026/P029 · 2026-11-20

Windows 本机语音按句合成到同一个 PCM WAV，并在每句结束后记录流位置。收据绑定句子、样本区间、完整旁白文本和原 WAV。工作台在开启字幕时显示旁白字幕，草稿中移动或移除音轨会即时更新。点击旁白字幕会定位时间并打开声音面板。旁白与交叉淡化的两组原声重叠时，预览与烧录使用三个位置。

导出 MP4 时可下载独立 SRT，选择烧入时字幕也会进入平台包内的视频。下载剪辑时间线会带上现有字幕，本轮读回 FCPXML 文本，实际编辑器导入待验。旧语音可继续播放和导出，有需要时可在声音页使用本机重合成取得新时序。
