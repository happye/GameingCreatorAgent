## 复测关注点

| 第五次反馈 | 本次试用怎么核对 |
| --- | --- |
| 同源片段重叠 | 篮里选入同一录像的两段重叠区间，核对去重后的时长与实际入选镜头。 |
| 需求、主题和拖拽 | 用同一句需求同时提出 1V1、3V3 和技能释放，核对类型、主题缺口及可预览方案，再拖动入点或出点。 |
| 音质与音量 | 听 60 秒样片的中文旁白，核对字幕与开口时间。在剪辑页查看原声波形和音量关键帧。 |
| 工程和命名 | 从指定版本进入，核对工作台能否保留当前作品和版本。作品显示名仍需完善。 |
| 文案和封面 | 发布页可改标题、简介和标签，或让 AI 起草。核对现有文案，改选封面候选再判断是否可用。 |
| 选段时长与成片时长 | 对照需求时长、篮内有效时长和成片时长。样片有 1800 帧、30 fps，重现原来的选段操作仍需从素材页走一遍。 |
| 创作环节的 AI | 从新需求生成方案并检查主题与镜头，再试一句话改镜。记录 AI 建议节省了哪些操作。 |
| 闭环与可发布性 | 先播放并下载指定 B 站包，再选择是否从新需求走完整流程。记录总用时、阻碍和成片能否直接发。 |

## 工程验证

Playwright 使用空白浏览器会话打开指定版本，核对两个复制按钮写入的链接，并在成片列表晚于发布区加载的情况下恢复指定 B 站包。预览视频元数据为约 60 秒，下载名为 `package.zip`，包含视频、封面、标题、简介、标签、平台配置和本地检查结果共七个文件，ZIP SHA-256 为 `66b9e218bedfa257e3a67549edc7a94772a093e715956ba5aa86ceac924dd`。

跨项目或已失效的任务链接停留在素材页并提示原因。加载期间手动切换项目，迟到的响应不会切回原项目。浏览器验证只发出 GET 请求。主验证记录在 `.cache/scratch/narration-captions-20261120/reopen-studio.log`。人评沿用 2026-11-11 第五次试用结论，下一次由你判断。
