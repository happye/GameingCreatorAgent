# 记录平台包的发布成效

R3 · P042 · 2026-11-20

在发布工作台展开某个已生成平台包的“发布成效”，记录观察日期、点击率、3 秒留存和完播率。可以只填已知项，或先登记帖子链接。指标空白显示“未知”，0% 保留为已知值。手录与测试分别标记。平台链接只作本机记录，由创作者填写。

记录固定关联项目、发布版本、平台包，以及已核对的发布回执、平台视频和 ZIP 摘要。每次不同观察追加一条，重复提交同一观察返回已保存记录，保留原登记时间。读取校验记录摘要，其他版本的观察不会混入。包队列刷新同一版本时保留正在填写的表单。

用漫画群星发布版本 `42f0de2b00554505a885b3349961f319` 及实际 B 站包 `918ebaca8e1e4069a7f42b2c61c21157` 实测。在工作台保存两条标记为测试的观察，覆盖 0%、空白、两位小数和帖子链接。关闭并重新打开浏览器后，两条记录连同来源完整回读。重试同一条得到原观察 ID，错配发布版本返回 400，另一支成片的 B 站包未混入记录。定向回归核对非法指标、跨项目绑定和被修改的本地记录。证据在 `.cache/scratch/publication-feedback-20261120/`。

真实平台数据待录入，推荐排序尚未使用成效记录。
