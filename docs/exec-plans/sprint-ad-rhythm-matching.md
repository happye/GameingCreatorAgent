# 广告配乐节拍匹配

R3 · P030 / P049 · 2026-11-21

Studio 的广告声音页提供按剪辑节拍、舒缓、动感和强烈四种偏好。按时长挑选最多六首已声明使用权的本机曲目，点击分析才解码每首开头最多 45 秒。排序比较本机估计的 BPM 和拍点，三种节奏偏好分别以约 80、115、155 BPM 为参考。界面显示实际核对了多少个切换、其中多少在拍点 75 毫秒以内。匹配使用输出时钟，连续原片按同速无转场条件合并，仅在确认音轨已完整解码时按解码长度处理循环。

持续音、静音、过短或低置信度曲目保留时长建议和手工选用入口。变速、裁剪、切换方案、改变偏好或曲库变化会使旧结果失效。选曲沿用原试听、保存和混音流程，曲目身份仍使用原登记回执。偏好描述表达用户想要的节奏，具体情绪、曲风和高潮解释待判断。

节拍提取和混音均使用登记文件的第一音轨。只允许本机文件解码，解码后复核媒体 SHA；45 秒预览和完整分析采用各自缓存键，并发写入用独立临时文件替换。已有资料和成片的原回执保留。

定向测试覆盖实解码的两个速度、按输出切换点排序、不同偏好的选曲结果、静音与恒定音、完整循环与未测区间、双音轨、媒体改变和并发缓存，共 22 项通过。
