# F006验收流程对抗审查与修复（2026-10-25第三会话）

所属阶段：Phase 0，F006（独立检索质量门槛）。主要交付：在用户确认分组、开始正式验收之前，找出并修掉会让验收结果算错、丢失人工判断、拦住正常流程或放过无效流程的问题。单Agent主控实现；审查用工作流＋独立评估（见下）。

## 一、对用户来说改了什么

- **计分不再把能过关的查询判成不过关（P0）。** 以前，如果前十名里某个事件先出现一段被评为0/1分的片段（例如剪得太短），后面同一事件的2/3分完整片段会被当成“重复”记零分。一个实际有7个不同可用事件的主查询会被算成6/10、判不过关。现在只有“已经按2/3分计入过的事件”才会让后面的同事件片段算重复；先出现的0/1分片段不占名额。命令行计分脚本`score-retrieval.ps1`同样修正。正式人工评分尚未开始，所以没有任何已有真实验收结论因此改变；旧的验证报告保留为历史。
- **边界被改过的旧评分不再冒充“重复”。** 片段起止和当时评审的不一致时，这一格算“未判定”（整条查询结果为空、需要重新评），而不是悄悄算成重复。
- **同一文件登记两次会在冻结时就提示。** 以前冻结显示“可以独立验收”，到关联步骤才失败；现在冻结直接给出“同一个文件（字节相同）登记了两次”。
- **原片标注页不再教人用错误方式登记。** 页面和指南以前说“同一动作起多个名字也保持同一归组”，但冻结会拒绝。现在改为“同一个动作只用一个事件名称”，两个名称共用一个归组时页面当场说明是哪个归组冲突。
- **登记表单改录像编号不会把别的录像的查询搬走。** 例如把`source-2`改成`source-11`时，中途短暂变成`source-1`，以前会把真正`source-1`的查询也一起搬到新编号；现在每个查询记住自己属于哪一行。
- **重新执行已完成的第2步会先确认。** 新标注页身份不同，旧页下载的记录不能导入新页；现在会先提醒并指向“打开原片标注页”继续标注。
- **指南里的冻结命令补上`-AutoInventory`。** 照原指南命令冻结会缺素材盘点，之后永远不能算独立测试集。
