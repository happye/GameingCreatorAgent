## 下一步按什么顺序推进

1. 盘点现有素材的真实录制来源与开发／独立测试用途，复用已保存原片参考；未确认项继续未知，不要求重标已有记录。
2. 用真实玩法素材补齐独立代表集和查询参考。准备／登记可以分批进行；正式主查询须事前有至少10个不同可用参考事件。查询、原片参考和录制分组确认后，先冻结评测计划，再分析或查看模型结果。
3. 需要新分析或定向补窗时，先形成具体来源、图片、参数与新增费用提案，再经明确授权执行；旧余额、旧v2或本轮开发许可都不授权录像请求。长钟馗三缺口的A/B/D沿原待办，已选C离线改进不等于选B。
4. 分析完成后，明确选择合格Completed版本，绑定事前已冻结的计划、生成固定排名，再请真人评前十位；缺位和同事件重复计零。用实际漏检／误检推进F009/F010，不以继续补词表或元数据断言代替主要质量交付。

当前没有正在运行的产品源码开发或录像分析任务；DSH本轮两轮实施已结束。本次只读素材核对由既有Luna/high完成，公共文档由Codex更新。人工待办只阻断依赖它的步骤，已有授权的独立离线开发可继续。

## 是否需要更多视频

**日常开发和复用旧结果不必马上补；正式F006验收需要更多代表性素材。** 规格目标是10–20段代表录像，并按原录制会话划开发／独立测试；不能用同一PV、剪辑或切片凑数。本机8个视频文件不等于8个已确认独立会话；当前登记三来源只按两个保守组处理（两钟馗暂同组、CIG一组），是否能全部计入正式集仍须确认。

下一批建议先准备2–3段可确认来源的真实玩法录制，覆盖Boss战／连招、剧情，以及确实存在的装备或武器菜单展示；长度不设新硬门槛，最终仍需小时级与代表性验证。先提供本机路径、所属原录制会话和能支持的需求，再补真正缺少的类型；不用复制原片或先付费跑模型。确实无某机制的片段可作为负例，尚未看清的继续记未知。

已有原片12条记录及用户纠正完整保留，修订副本10个有效样例为Boss1／连招5／剧情4；是合计10个，不能当作某个主查询已有10例，也不代表穷尽全片。两处长剑特写依原口径排除，“武器菜单展示”仍无已确认例。新增素材仅补新增来源／事件，不重做这些标注。具体入口、触发和状态见[人工待办](human-inputs.md)。
