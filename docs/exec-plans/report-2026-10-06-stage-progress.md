# 阶段汇报：已有动作片段更容易找到

2026-10-06。继续沿总方案和Phase 0开发，所有Agent的通俗详细汇报规则已持久化。最近一轮补齐了中文动作别称，并核对了全部已有完成分析的来源。

现在可在本地工作台打开已有分析、回看原视频、查看证据和描述、搜索候选，再收入按原时间排序的片段篮并导出JSON／CSV。完成搜索后可打开“检索诊断 · 前十位”，查看原排名、缺位和已知重复，直接回看并下载本次快照。查询或项目变化后旧诊断失效，迟到／失败结果不能恢复旧下载。

查找已有动作时，不必反复试不同说法。“起跳”“跳起”能找到原文写作“跳跃”的记录，“交互”“互动”也相互对应；英文jumping、interacting同样覆盖这些中文别称。实际Atom实机两个版本的“起跳”从零条变两条，默认新版“交互”从一条变两条，旧实机从一条变三条，Atom PV旧版从零条变四条。这只改善已保存文字的查找，不会补造视频动作。

来源清单为四份完成分析、三个视频文件、260事件；两个分析来自同一段54.743秒Atom实机，Atom不同文件也可能同源，不能当独立最终验收集。漫画直接搜jump的五条来自游戏标题／版权文字，之前误称动作标签已立即纠正；中文跳跃或jumping不会因为本轮别称扩展而把这些标题纳入动作结果。详细例子见[已有录像审计汇报](./report-2026-10-06-retrieval-corpus-audit.md)。
