# 阶段汇报：现在能怎么用，接下来先解决什么

2026-10-06。沿已对齐的总方案和Phase 0路径继续开发，并加载所有Agent的持久汇报规则；最新切片修复了英文动作词漏掉已有中文描述的问题。

现在可在本地工作台打开已有分析、回看原视频、查看证据和描述、搜索候选，再收入片段篮并导出JSON／CSV。完成搜索后可打开“检索诊断 · 前十位”，按原排名查看候选、缺位与已知重复，直接回看并下载本次快照。修改查询、方式、条数或项目／运行后，旧诊断关闭，迟到或失败结果不能恢复旧下载。

最新改善是同一动作可以用有限的中英文词查询。Atom新版分析中，jumping词法从零条变为两条，混合从一条变两条；move／moving也能找回与中文移动对应的已有候选。旧版也找回了这些中文描述。中英文混写、大小写、全角英文和明确“未见jumping”经过验证；没有重新分析视频。两个版本实际属于同一54.743秒Atom录像，不能当两段独立录像。三十组中文查询原结果保持，详见[英文动作汇报](./report-2026-10-06-retrieval-query-audit.md)。

射击与Boss的困难仍保留。两版已保存文字没有射击、开枪或发射支持，射击仍零命中，不能因此断言录像里没有对应动作。新版Boss长句的文字命中分别来自boss标签和冲击波，缺铠甲、领主和权杖的支持；返回八条不能证明整句成立，旧版返回十条也一样。下一步把原因审计扩大到其他已有完成分析的录像，区分文字缺失、否认误命中、词法漏检和纯语义误返，先使用现有数据。

你此前确认的35–36秒三个描述和28–29秒“近镜头物品不是新人物”的纠错仍可看到。条件草稿可把发色、衣着和持有物变成可编辑清单，在同一主体／实际部件／有支持帧的条件下核对；不支持的要求保留。普通自由搜索尚不能保证复杂长句的全部条件或主体关系。

旧版／新版对照页和本地人工记录页仍可用，原六张画面、旧描述及你的意见可一起看，四维分别填写／下载／载入并核对来源后归档。新精分析两个真实请求尚未执行，相关判断禁填；实际仅完成空记录往返，没有新增真实人评。连续实体规则已通过程序检查，但近镜头物品误认是否真的改善仍待新实际结果。
