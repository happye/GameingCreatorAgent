# P025：解说模板草稿（单Agent）

2026-10-31，Claude Code主控实现。目标：把已保存剪辑版本的镜头分析描述变成一段可朗读、长度合适的中文解说草稿，一键填入R2-I旁白。

## 合同

- 只读已保存版本（plan/revision链）的镜头scriptDraft、Brief的游戏名与内容类型、成片帧数/fps；不调用模型、不产生费用、不写文件。
- 预算=成片秒数×3.5字/秒×0.9（本机Huihui实测21字5.688秒≈3.7字/秒）；开场按内容类型（玩法速览/攻略要点/活动投稿）。
- 每镜头取第一句可见描述，去掉f0等帧号标记，长句按逗号截断，不补词、不加省略号；连续重复描述只保留一次。
- 单段旁白覆盖整片，按成片时间均匀抽取能放下的最多镜头；返回未写入镜头数，状态template-draft-human-review-required。
- 接口GET /api/creation/jobs/<id>/narration-script?planId=；页面按钮填入旁白文字并显示估算与核对提示。

## 结果
