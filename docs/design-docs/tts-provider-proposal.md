# 语音合成（旁白配音）提供方方案 — 待用户批准

日期：2026-11-03 · 状态：**云端试听已批准**（2026-11-03）；本机模型下载未批准

## 现状

- 已有：Windows 自带语音（SAPI），离线、免费，本机可用的中文声音只有 “Huihui”，听感明显机械。工作台第 4 步先把它接进来，保证旁白流程本身能跑通。
- 工程上：旁白已是独立的“旁白素材任务”（文字 + 声音 → WAV + 回执），版本里只引用素材的回执哈希。换提供方只需新增一个合成器，文字、对齐、混音、版本、渲染都不用改。
- 旁白不会被截断：旁白比成片长时直接拒绝，并提示“改短文字、调整起点或移除旁白”。

## 用量估算

旁白稿按每秒 3.5 个汉字估算：60 秒成片约 210 字；3 分钟成片约 630 字。

## 建议

1. **先做 A**（便宜、中文好、有免费额度），同时保留 Windows 语音作为离线兜底。
2. **B 作为第二步**：你的显卡足够，长期零费用；但要先同意下载。
3. 费用闸门：沿用现有的付费调用闸门，单独设一个“旁白配音 ¥5/月”的预授权；超出时再问你。每次合成前显示字数和预计费用，同一段文字与音色重复合成直接复用已有结果，不重复付费。

## 试听（已批准，由你在自己的终端运行）

- 修正：v3.5-flash 没有系统音色（只能用复刻/设计音色），试听改用 **cosyvoice-v3-flash**（1 元/万字符）的系统音色：龙修、龙悦、龙安洋、龙硕。4 个音色约 560 计费字符，约 **0.056 元**。
- 接口：百炼 HTTP 非流式合成（`POST …/api/v1/services/audio/tts/SpeechSynthesizer`，返回 24 小时有效的音频地址，下载后保存）。代码：`src/gamingcreator/infrastructure/cosyvoice_tts.py`；脚本：`scripts/tts-audition.py`（不加 `--send` 只显示字数和费用；单次上限 1000 字符；已有音频的音色不再付费；每次调用前后各记一行到 `audition.json`）。
- Key 只放在你终端进程的环境变量 `DASHSCOPE_API_KEY`，不写入任何文件。

## 原试听方案

- 固定 3 句旁白（开场钩子、玩法说明、结尾号召，共约 80 字）。
