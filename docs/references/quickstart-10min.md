# 10 分钟上手：用一段录像做一条视频

不用读别的说明。整个过程在本机完成，不花钱。

1. **打开工作台**：双击仓库根目录的 `Start-Workspace.cmd`。浏览器打开后，点右上角的 **「创作视频」**。
2. **选素材**：选项目，勾选一段录像。只有已经分析过的录像才会出现在列表里。
3. **类型与时长**：填游戏名，选内容类型（例如“玩法展示”），填目标秒数（默认 60），然后点 **「生成方案」**。其他选项都收在“高级选项”里，不用填。
4. **选方案**：会出现 4 张方案卡。每张卡写着时长、镜头数和前 3 个镜头。挑一张，点 **「选择此方案」**。
   - 第一张是按内容类型推荐的模板。
   - 另外三张是通用顺序：按录像顺序、最后一段开场、倒序回顾。
5. **生成视频**：页面会自动跳到编辑区。不想改镜头的话，直接点 **「将所选方案生成视频」**，大约一分钟后在“4. 成片”里就能播放和下载。

## 常见疑问

- **按钮是灰的？** 按钮旁边会写原因。最常见的是“先选择方案”，或者“有未保存的镜头修改”。
- **刷新或关机了？** 第 1、2 步填的内容会自动保存，下次打开会恢复。不想要了就点“清空草稿”。
- **右侧“我的作品”**：按类型列出以前生成的视频、方案、封面等，最新的在前。点一项会跳到对应的位置。
- **方案的文字说明**：这些文字来自录像分析时保存的描述，工具并没有真正“看懂”画面。生成后请自己看一遍成片。
- **更多功能**（封面文案、平台预览包、活动规则、游戏知识、套餐、团队审核）：见[创作全流程手册](creation-guide.md)。
