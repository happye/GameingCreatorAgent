# 一次搜索多段录像

选择同一项目内几个已完成分析的任务，一次查询它们的内容。候选统一按相关性排名，显示原录像名称、时间码、模型描述和待核对内容；不同录像发生在相同时间的片段都会保留。准备完成但还没做模型分析的任务不能参与搜索。

## 选择和搜索

先用现有任务清单找出已完成任务的`runId`：

```powershell
./scripts/list-tasks.ps1 -Project artifacts/demo-phase0
```

在仓库根目录用项目已有PowerShell 7执行，例如搜索三段已完成开发录像：

```powershell
./scripts/search-project.ps1 -Project artifacts/demo-phase0 -Run f601fb9b3e734d5ea188fc15c790acbb,c6d93b984f374cd4aa755ed0c81e4d73,f76f5d6495314c04ae04083614d4afd6 -Query "角色移动"
```

这里明确选择Atom v6、另一段Atom录像及漫画录像，没有选同一Atom素材的v4版本。一批接受1–100个不同任务；同一原视频的两个分析版本会被拒绝，需要选其中一个。程序不会替你切换版本或把未完成任务恢复成已完成。

默认`hybrid`结合词法和本地E5语义匹配，需要项目已有的本地模型。`-Mode lexical`只按文字检索，不需要语义权重。`-TopK 20`改变最多返回的候选数，不能超过100；没有命中时保留空结果，不补片段。`-MinSimilarity`仅改变未经过人工校准的语义阈值，不代表准确率。加`-Json`输出完整来源和结果，默认输出便于阅读的清单。

它不需要API密钥，不调用ASR或视觉模型，不上传素材、不预留费用。本地语义模型会使用CPU和项目缓存；零API费用不表示硬件成本已测量。进入检索前，程序核对所选任务和原文件；任何一项不完整或损坏都会停止，不能把缺少来源的部分结果冒充整批完成。

## 找回这次结果

输出给出`searchId`和`recordPath`。记录在`<项目>/project-searches/<searchId>/result.json`，对应SHA回执保存最后发布的结果。每次查询使用新的目录，保留最初的候选排名和来源；它不改旧任务、旧检索记录或人工评审依据。

每个候选含`runId`、`mediaId`、原`candidateId`、`startUs/endUs`、画面／音轨证据、原始描述和`uncertainty`；`rank`表示这次联合语料中的位置。来源列表记录原文件SHA、时长、配置／管线身份和原分析配置。换选择的录像会改变检索范围和排名，即使需求相同也不保证得到相同分数。分数是排序依据，不能当作内容匹配概率。

可以在现有工作台选择候选的原任务，按输出时间码回看原片。这轮入口是脚本／CLI，网页里的搜索仍是原单任务模式；下一项交付会把联合检索接到本地检查流程。

开发工具调用也可使用：

```powershell
. ./scripts/env.ps1
./.venv/Scripts/python.exe -B -m gamingcreator search-project "角色移动" --project artifacts/demo-phase0 --run f601fb9b3e734d5ea188fc15c790acbb --run c6d93b984f374cd4aa755ed0c81e4d73 --mode lexical
```

结果版本`project-search-v1`／检索版本`bm25-e5-rrf-v7-project-v1`与原单任务、benchmark记录分开。查询范围有稳定`scopeId`，输入任务顺序不同不会改变范围或排名；它只标识来源和配置，不证明录像来自独立录制。`elapsedMs`包括源资料验证和检索、截至保存前，`sourceValidationMs`单列核对时间。

## 验证边界

真实三开发录像的“角色移动”前十同时包含三个来源；词法约0.45秒、本地语义结合约3.9秒，公开脚本和另一个进程读回的排名一致。初次实测三次查询后，校验脚本误假设长负面查询必须为空；保留三条原记录，修正校验预期后新增四条验证记录，总计七条，不删除或覆盖失败前的结果。

“不存在的星际交易飞船维修机制”实际仍有一个词法候选：查询里的“存在”匹配了原描述里的“仍存在”。这是已有负面意图与整句匹配的不足，记录在TD004，尚未修复；不能把一个泛词命中解释为满足整句。原单任务算法及此限制保留，不用本轮交付宣称检索质量通过。独立人工F006验收仍待完成，详见[本轮任务和证据](../exec-plans/sprint-project-retrieval.md)。
