# 多录像复合条件核对

想找“白发、手里拿杖的同一个人物”时，可以对明确选定的录像核对已保存的细节，不必逐个候选点开条件页。这项操作检查所选分析版本的全部事件，再显示筛选结果；不经过搜索前十名截断，也不启动新精分析。

1. 在主工作台选择项目和已有分析，点“选择多段录像”，勾选不同录像的已完成版本。
2. 左侧明确选择精分析版本，点击搜索区“核对复合条件”。弹窗会显示所选录像数量和版本。
3. 填写明确条件，或先生成可编辑条件再核对。各项必须同时满足；同一衣物或持有物的条件使用同一部件组。原句中未能理解的要求仍须明确确认只核对当前子集。
4. 点“核对已保存结果”。可筛选全部满足、部分满足、尚未验证、有证据不符，翻页并展开依据。
5. 点“回看此片段”打开对应录像的原区间；“下载本页核对结果”保存当前页及总计、条件、版本和结果快照。需要其他页时翻页另存，不把单页下载当全库导出。

“全部满足”表示同一主体／部件有共同支持画面，仍需人工回看。“部分满足”表示部分条件有支持，其余缺失或不确定。“尚未验证”通常表示该准确版本没有足够已保存细节，不能据此断言原片没有。“有证据不符”保留原匹配器的明确相反证据判断。不同录像、人物或镜头的属性不会拼成一个完全匹配。

同一原录像的旧版和新版分析只能选一个；基础分析版本或精分析版本不同，不能借用另一个版本的结果。当前三个开发源的旧基础v4组合有227事件，“白发＋持杖”实测0全部满足、1部分满足、226未验证，约0.8秒；换基础v6后共220事件均未验证。没有新模型调用、搜索记录或费用，但这些结果不能证明内容质量验收通过。

默认每页20条，接口允许1–50条；最多100个不同任务、20,000事件，超过明确报错、不截断后称全部核对。翻页和换筛选复核全部结果快照；若保存的细节已改变，旧页被拒绝，需重新核对。

命令行同样可读已有结果：

```powershell
./.venv/Scripts/python.exe -B -m gamingcreator match-project-details --project artifacts/demo-phase0 --run <任务1> --run <任务2> --input detail-query.example.json --profile v2 --status partial
```

`--limit`、`--offset`控制分页；`--snapshot`接受上一响应的snapshotId，防止跨不同结果翻页。没有保存选项；输出自行存文件。正式人工检索验收使用[验收流程](benchmark-workspace-guide.md)，日常条件核对不要求填写验收表；人工待办见[当前清单](../exec-plans/human-inputs.md)。
