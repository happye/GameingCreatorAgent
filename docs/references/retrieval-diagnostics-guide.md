# 查看检索诊断

检索后可以看到前十个位置的情况，帮助分清“没有返回足够片段”和“有候选但还不知道是否有用”。例如搜索跳跃只返回两条时，诊断会显示两条候选和八个缺位；不会把两条结果当作十条中的全部成功。

1. 双击仓库里的 `Start-Workspace.cmd`，打开一份已完成的分析。
2. 填写查询，选择检索方式，将候选条数设为至少十条，点击“查找片段”。
3. 检索完成后点击“查看检索诊断 · 前十位”。按原检索顺序查看十个位置，点击“回看这个片段”会返回原视频对应区间，并显示已有证据。
4. 点击“下载本次诊断”，保存查询、检索方式、来源身份、原排名、区间、证据和缺位／重复情况。文件仅用于记录这次检索，没有人工评分。

同一事件重复出现会标明它重复了哪个位置。不同事件编号仍可能来自同一个实际动作，需要观看原片判断。第十一条和更后面的候选不会填补前十位的缺位或重复。

每条候选还显示它实际引用了几张登记画面、来自几个时刻和覆盖多久。只有一张图时，提示这份记录不能确认动作过程；多张图仍须回看主体和镜头变化。相同时刻的多图、不同时间但文件内容相同、仅音频及登记资料不完整分别说明，不自动判成动作正确。窗口曾发送多张图，不代表每条候选都引用多张；例如旧Atom PV的移动前十候选，每条实际只登记一张。下载同时保留这些来源时刻与图片摘要，人工评分仍为空。

如果候选条数主动设为小于十，页面会提醒缺位包含本次条数限制。先调到至少十条并重新搜索，再判断是否返回不足。纯语义检索即使返回十条，也可能与查询无关；“待人工核对”不代表模型已经找到十条可用片段。

修改查询、检索方式或条数，切项目／运行，刷新或重新检索后，旧诊断会关闭。完成当前查询后重新打开即可。空查询、未完成的分析和失败的检索没有可下载的完成诊断；成功检索但没有命中会明确保留十个缺位。

打开诊断、下载和回看不再执行检索或模型分析。普通搜索仍沿原流程保存本地搜索记录；这个入口不写人工标签、不修改已有分析或费用。正式检索验收继续按 [F006人工验收指南](./human-acceptance-guide.md) 使用独立素材与人工判断，详见 [固定十位基准规则](./phase-0-benchmark.md)。
