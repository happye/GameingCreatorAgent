# Golden principles

1. Keep source game videos local by default; send only selected evidence to remote model providers.
2. Make AI output a structured, inspectable decision with source timecodes and version metadata.
3. Keep model providers replaceable and observe cost, latency, and failures.
4. Do not hide platform rules or prompts in hard-coded branches; version them as data when introduced.
5. Validate paths, media inputs, model responses, and SQLite writes at their boundaries.
6. Preserve the Phase 0 quality gate: retrieval accuracy comes before a desktop UI or commercial workflow.
7. Change documentation when implementation changes a documented command, boundary, or decision.
