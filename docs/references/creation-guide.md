# 创作方案和剪辑决策

当前首版支持结构化需求和离线模板，使用明确选中的Completed分析素材；不调用模型，不产生新分析费用。它保留原分析和素材，写入全新的创作目录。

## 在工作台里用（推荐）

1. 启动工作台，点击“创作视频”；或打开同一服务的`/creation`页面。
2. 选择已有项目，勾选“已完成分析的录像”；填写游戏、内容类型、平台、目标秒数、目标和可选主题/排除项。
3. 点击“生成三种模板方案”，查看草稿和缺口；有缺口的方案不能渲染。
4. 明确选择一个可用方案，选横屏/竖屏尺寸和字幕方式：不加字幕、导出SRT、烧入视频并导出SRT；点击“将所选方案生成视频”。本地后台处理，可查看任务状态。
5. 完成后直接播放、下载MP4和可选SRT。字幕来自对应分析版本已保存的语音；没有语音时明确显示0条，SRT为空，不用画面描述编造对白。刷新或重启服务可以从历史找回已完成结果，不自动重复生成；失败/中断会说明状态，重新生成是显式新操作。

选择方案后，“调整镜头”可以修改原录像入点/出点（显示按帧吸附的实际出点）、上下移动或删除；至少保留一个镜头，只能在当前父版本范围内裁短。先“保存新剪辑版本”，再生成视频。可从历史打开剪辑版本，选择祖先版本恢复之前的镜头；旧方案、旧成片和原录像均保留。恢复删去/裁去的内容需选回祖先再编辑，也可以从根请求已选录像中选择其他已保存事件替换，见下方。

每个镜头还可勾选“手写字幕”，填写整段文字（最多2000字），保存新版本后选“烧入视频并导出SRT”。手写文字替换该镜头原语音字幕；勾选但留空明确关闭该镜头字幕，取消勾选恢复已有语音。没有已保存语音也可以手写；文字随镜头裁短/换序映射，祖先版本可以恢复旧文字，不修改原转录。

“配乐与音量”可以选择已登记本地音乐，分别调低原声和配乐（-60至0dB），勾选按原声能量压低配乐，或移除音乐。先保存新版本再生成；改镜头或字幕会保留配乐设置，祖先版本可恢复。音乐从曲首连续播放，短曲循环到成片结束。压低配乐响应游戏音效和人声，不区分旁白。

登记自己的本地音乐（不会下载或上传）：

```powershell
./scripts/register-music.ps1 -InputPath <本地音频> -Title <曲名> -SourceDescription <来源说明> -LicenseStatus user_declared -LicenseEvidence <可选许可材料>
```

LicenseEvidence可省略，许可状态为unknown/user_declared/test_only。声明和附件不等于权利已核实；本地测试音调明确仅测试用途，不可当正式商用授权音乐。音乐和许可材料按SHA登记，原文件保持。

当前仍是离线模板、基础渲染和部分编辑，不代表通用AI、完整模式成片或正式人评。字幕逐词时序/样式、本地旁白接入、AI选曲/节拍匹配等待补。只操作已有分析，不产生新模型费用。

成片完成后，“封面与文案”可用当前播放位置选择封面帧，编辑标题/简介/Tags并保存为独立版本。完成后预览PNG并分别下载cover.png、title.txt、description.txt、tags.json、publication.json；历史可重开旧版继续编辑。只提取已有视频帧，不重新生成视频、不产生模型费用。文案为可编辑模板/用户文字，尚未人评；此五文件功能不代表四平台完整发布包。

如果电脑仍运行旧版工作台、没有“创作视频”入口，可用`./scripts/start-workspace.ps1 -Port 8766`另开更新服务；不需要关闭或中断原任务。已安装桌面EXE的自动升级仍属后续交付。

下面CLI仍可用于开发和批处理，不要求日常用户手写JSON。

## 1. 填需求

复制仓库根的creation-brief.example.json，填写游戏、内容类型、平台、目标秒数、目标、观众、语气、必须主题和排除项。targetDuration必须为1–86400的整数秒。当前不是任意自然语言理解；未识别的创作意图不应视为已理解。

## 2. 生成方案并选择一个

```powershell
./scripts/plan-creation.ps1 -Project <项目目录> -Run <Completed版本ID> -Brief ./creation-brief.example.json -OutputPath <新的创作目录> -Select hook-first
```

Run可显式选多个版本；Event可进一步指定事件。支持chronological（同源按原时间）、hook-first（末段作为开场，再回溯）、reverse（倒序）三种模板。没有Select时只保存方案；选中可用方案才写edit-decision.json。

plans.json保存三种方案、原片段、可编辑描述草稿和缺口；receipt.json绑定完成文件SHA。少于3个不同源区间或必含主题缺已保存文字支持时，方案不可选，不会复制素材凑数。同源同区间跨分析版本只算一份；不足一个输出帧的片段不进入模板。

脚本目前是已有描述草稿，不代表真人确认、完整解说或玩法事实保证。必含主题检查只查保存文字，不证明画面理解；更完整的脚本/知识/素材评分按产品路线后续实现。

## 3. 真实渲染（首版已交付）

render-creation / scripts/render-creation.ps1接收项目、已完成创作目录和新输出目录，按选择方案的创作顺序生成video.mp4。实现状态、验证和已知限制见[渲染sprint](../exec-plans/sprint-creation-render.md)及[字幕sprint](../exec-plans/sprint-creation-subtitles.md)；未有完成回执的目录不算成片成功。已支持原片裁剪、拼接、缩放/留边、音轨及已有语音字幕，工作台剪辑版本还支持逐镜头变速和交叉淡化。

字幕可传`--subtitles sidecar`（只导出）或`--subtitles burn`（烧录并导出）；PowerShell对应`-Subtitles sidecar|burn`，缺省none。输出新增subtitles.srt，SHA写入receipt.json；中文烧录使用系统可用字体，无新下载。烧录按百分之一秒量化，反斜杠/花括号显示为全宽字符，原SRT文字保留；字幕准确性仍需审片。

现有输出目录不会覆盖，原素材/项目和已有创作目录不可用作输出。源文件变动、来源或回执不符会拒绝，不能仅改JSON路径指定任意原片。

完整路线：[全51项计划](../exec-plans/accelerated-product-roadmap.md)。你现在必须做的人工任务为0项；后续触发与数量标准见[人工清单](../exec-plans/user-actions.md)。

```powershell
./scripts/render-creation.ps1 -Project <同一项目目录> -Creation <上一步创作目录> -OutputPath <新的成片目录> -Width 1280 -Height 720
```

完成目录含video.mp4、可选subtitles.srt与最后完成回执；实际首闭环样例为865帧、30fps、28.83秒。GUI表单、字幕选择及下载均已接入，可直接在工作台操作。

## 四平台本地预览包

保存封面文案后可选择B站/抖音/快手/小红书，修改视频/封面尺寸和补边或裁切方式、文件大小/时长/文字/必需标签等本地限值，每次生成一个平台。完成后下载package.zip（仅含video.mp4、cover.png、title.txt、description.txt、tags.json、platform.json、validation.json），也可分别下载。旧任务始终使用当时保存的配置，刷新/重启不重复编码。

这些是可编辑本地导出配置，非已核官方规则。生成成功只表示文件已生成；本地超限会明确未通过，未设置的限值显示未配置。平台规则、素材权利和人审未知时资格仍未核实；测试用途音乐会阻止发布资格，本地预览包仍可下载检查。此批未自动调整Hook/CTA/时长，不自动发布，也不表示可商用投稿。简介可保留多段换行。

## 逐镜头变速

镜头行选择0.5x/1x/2x后，入出点继续表示原录像秒数；界面显示新的输出帧数和时长，不会偷偷扩大源区间。保存新版本再渲染，原声音高保持，已有语音/手写字幕同步到输出时间，配乐按成片时间连续播放。慢放可以超过最初目标，界面会显示差异；这不改变原Brief。尾端不足一输出帧的余量舍弃，原入出点保留。祖先版本可恢复原速度；旧v1任务原样可读/下载。开发接口新v2需显式startUs/endUs/speed，不可把旧outputFrames当源长度。

## 交叉淡化转场

第二个镜头起，每行可选择“直接切换”或“交叉淡化”并填写重叠帧数。例如30fps下两个各30帧镜头重叠6帧后是54帧（1.8秒），第二镜头从第24帧开始。页面显示真实总长和各镜头起点；保存新版本后渲染，画面和原声一起淡化，字幕跟随重叠后的时间，配乐从成片零点连续播放。

首镜头固定直接切换。每个镜头入场与出场重叠帧数之和必须小于镜头输出帧数，至少留一帧独占；非法值会阻止保存。换序/删除后，新形成的连接恢复直接切换，原相邻连接设置保留；可以重新选择淡化，祖先版本可以恢复旧设置。

烧录时重叠段的常规短字幕上下分层，其余时间恢复底部。任意长文的多行排版尚未全面验证，仍需审片；SRT保留两段真实时间，播放器自行决定重叠字幕排版。开发接口v3沿v2字段增加transitionIn={type:cut|crossfade,frames:整数}，旧v1/v2文件不改写。刷新时已选任务独立恢复，不再等待整份历史列表核验。

## 选择其他事件替换镜头

每个镜头点击“选择其他事件替换”，列表按录像文件名、原片秒数和已有描述列出事件。范围是生成根方案时明确选中的全部已完成分析录像；即使一段录像还没出现在成片里，也能从它取候选。不填写原片路径，不新增分析或费用。

选择候选后会核对原片播放时钟再预览；某些格式或时钟无法核实时明确显示预览不可用，仍可明确选择后查看成片，不会假装已经定位。较慢的原片读取最多为每次定位等待10秒，未收到定位完成仍拒绝确认时钟。确认替换后默认速度1x、源区间不长于旧镜头输出时长，并显示帧数变化。

旧镜头的手写字幕不会移到新画面，新镜头使用对应分析版本已有语音（无语音则无字幕）；其他字幕、配乐和音量保留。新镜头与后一镜头的入场连接恢复直接切换，其他原连接保持。先保存新版本取得新镜头身份，再调整其速度/字幕/两侧转场；保存后也能继续裁短、换序、重渲染，祖先版本可以恢复原画面和文字。

新修订v4冻结候选清单及根来源，后代继续携带同一清单；旧v1–v3文件保持。选错项目、清单/来源/父版本发生变化时会拒绝，需重新打开。当前仍是离线候选手选，不代表模型已选准镜头、自动创作质量或商用权利已验收。
