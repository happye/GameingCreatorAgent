# 创作全流程手册（安装 → 发布包）

面向日常用户的通俗说明：从把程序装到本机，到在工作台里准备录像、生成方案、成片、封面文案，再到四平台本地预览包与本机「沙箱发布」。
更偏检索／分析／验收的命令行说明见 [user-manual.md](./user-manual.md)；本页专讲**创作闭环**。

**诚实边界（全文适用）**

- 默认是**本机**工具：不替你登录平台、不代你付费、不自动往真实站点投稿。
- 「套餐与用量」是**本地评估开关**，不是支付或订阅。
- 「沙箱发布」只在本机模拟流程，**不会上传**。
- Free 成片会烧入半透明水印「GamingCreator Free」；分析／视觉云端调用仍须另案批准，本手册不代你发起。
- 模板方案按已保存文字与规则拼装，**不代表**已经看懂画面或通过人工质量验收；内容模式统一写明「描述代理评分、非画面理解／未做人评／投放未验证」（见第 6 节与工作台方案卡）。

## 0. 你需要准备什么

| 项目 | 说明 |
| --- | --- |
| 系统 | Windows；桌面窗口依赖本机已装的 WebView2 运行时（没有时可能退回 Edge 应用窗口） |
| 素材 | 本机录像文件；正式检索质量验收另见验收流程，不挡日常创作试用 |
| 权限 | 不写注册表、不改系统目录；安装默认在当前用户目录 |

## 1. 组装便携目录（开发机 / 维护者）

### 入口

仓库根目录 PowerShell：

```powershell
. ./scripts/env.ps1
./scripts/build-app.ps1          # 可选 -Smoke 装完后自检启动
```

产物：`dist\GamingCreator\`（约数百 MB～1GB 级，含运行时、FFmpeg、桌面程序、`models\`、`licenses\` 等）。

### 会发生什么

- 生成可整体挪走的文件夹；内含 Python 运行时、依赖、FFmpeg、`desktop\bin\GamingCreator.exe`。
- 打进本地 ASR／嵌入模型到 `models\`（装好后可做新录像的语音与本地检索，不必再指开发机 `.cache\models`）。
- 生成 `licenses\`：汇总本机已有的第三方许可正文到 `THIRD-PARTY-NOTICES.md`；缺正文的记在 `gaps.json`，**不下载、不猜**。
- 数据日后写在该目录下的 `.cache\`。

### 不会发生什么

- 不会安装到系统目录，也不会默认创建开始菜单项。
- 不会联网拉取模型或 FFmpeg；缺许可正文不会被自动补全。
- 不会宣称代码签名或「另一台干净机器已验收」。

### 常见问题

- **目录已存在且不是本脚本生成的？** 脚本会拒绝覆盖，以免误删别人的文件。
- **体积变大？** 内置模型后体积显著增加（曾测约 866MB，上限设计约 1.5GB）；这是预期。
- **只想开发调试？** 可不走便携包，直接用仓库里的 `Start-Workspace.cmd` / `scripts/start-workspace.ps1`。

## 2. 安装 / 升级 / 卸载

### 入口

先有上一步的 `dist\GamingCreator`，再在仓库根执行：

```powershell
./scripts/install-app.ps1
# 常用可选参数：
#   -Destination <路径>     默认 %LOCALAPPDATA%\Programs\GamingCreator
#   -StartMenuShortcut      可选：在开始菜单 Programs 下创建 GamingCreator.lnk（默认关闭）
#   -Smoke                  装完做一次启动自检
#   -Uninstall              卸载程序（默认保留用户数据）
```

### 会发生什么

- **安装**：把程序部件（运行时、依赖、FFmpeg、桌面程序、脚本、`docs`、`models`、`licenses` 等）拷到目标目录。
- **升级**：只替换程序部件；`.cache` 里的创作、账本、日志以及你的项目／成片文件夹**原地保留**。中途失败会尽量恢复旧程序。
- **卸载**：去掉程序部件；有用户数据时保留并留下标记，以便同一路径重装继续用；记录里若曾创建开始菜单快捷方式，卸载只删**那一个**记录中的 `.lnk`。
- 不写注册表、不改系统全局设置。

### 不会发生什么

- 默认**不会**创建开始菜单快捷方式（必须显式 `-StartMenuShortcut`）。
- 不会自动删除你的创作数据；不需要时请自己删整个安装文件夹。
- 不会在程序仍在运行时强行覆盖（需先关窗）。

### 常见问题

- **目标目录已有无关文件？** 既不是本应用、也没有「卸载后保留数据」标记时，安装会拒绝，避免误用别人的文件夹。
- **重装后数据在哪？** 还在同一 `-Destination` 的 `.cache` 等用户条目里。
- **快捷方式怎么来的？** 只有安装／升级时加了 `-StartMenuShortcut` 才会建；升级不加开关时，若收据里已有快捷方式则保留。

## 3. 启动工作台

### 入口

任选其一：

- 安装／便携目录：双击 `desktop\bin\GamingCreator.exe`
- 开发仓库：双击根目录 `Start-Workspace.cmd`，或 `./scripts/start-workspace.ps1`（可 `-Port 8766` 另开端口）

浏览器或内嵌窗口打开后，点右上角的 **「创作视频」** 按钮（地址 `/creation`）。只想快速做一条视频，看 [10 分钟上手](quickstart-10min.md) 就够了。

### 会发生什么

- 本机随机或指定端口拉起服务；桌面 EXE 用独立窗口（优先 WebView2）。
- 重复启动已在运行的实例时，通常会提示已在运行，而不是再开一套互相打架的服务。
- 日志在安装／便携目录的 `.cache\desktop`（或开发树对应缓存）。

### 不会发生什么

- 不会自动开始分析或扣费。
- 不会连接真实视频平台账号。
- 关窗应停止该次宿主拉起的服务；不保证清理你用别的方式手开的进程。

### 常见问题

- **旧窗口没有「创作视频」？** 多半是旧构建；可用新端口再开一版服务对照，不必强行杀掉正在跑的长任务。
- **只有 Edge 小窗？** 本机 WebView2 运行时不可用时的退路；站外链接仍走系统浏览器。

## 4. 准备录像（本地，可计量）

### 入口

工作台「准备录像 / 准备多段录像」；或开发用 CLI／脚本（见媒体准备相关指南）。

### 会发生什么

- 把本机路径登记成素材任务，做离线准备（封装／校验等），**等待你再显式分析**。
- 若当前套餐是 **Free**：新提交成功**接受**时，用本机 ffprobe 读时长，按自然月累加到 `.cache/workspace/creations/entitlement-usage.json`；**每月最多约 60 分钟**准备额度。「套餐与用量」可看到本月已用准备分钟。
- **接受时记账**：之后该批失败／取消仍占用当月额度；**续跑不重复计**；同一项目＋相同路径本月已记则不再加。

### 不会发生什么

- 准备本身不调用付费视觉，也不等于分析已完成。
- 不会在未切换套餐时悄悄「购买」加量；超额会拒绝并给出中文说明。
- Creator／Pro／创始人验证版不限制准备分钟。

### 常见问题

- **为什么失败了也扣分钟？** 政策是「接受任务时入账」，避免靠故意失败刷免费准备。
- **只改参数重试？** 走续跑／原任务续跑路径，不应再次累加同一路径的本月额度。

## 5. 分析素材（创作前置）

### 入口

素材任务里对已准备条目发起分析（工作台或 CLI `analyze` 等）。创作页只能勾选 **已完成分析** 的录像。

### 会发生什么

- 生成可检索／可引用的时间线与描述等本地结果；具体费用与是否出网取决于你配置的 Provider 与是否已批准的发送。
- 便携／安装版可走内置本地 ASR 与嵌入模型；云端视觉帧仍属另案。

### 不会发生什么

- 本手册**不**授权任何新的付费视觉或补窗；缺批准就不要发。
- 分析完成 ≠ 人工质量验收（F006）通过。
- 不会因为打开创作页就自动重跑分析。

### 常见问题

- **创作页灰掉某些录像？** 未完成或不可用的分析版本不能勾选。
- **想省钱？** 只用已 Completed 的本地结果做模板创作；模板路径本身不新扣模型费。

## 6. 填写需求并生成三种模板方案

### 入口

`/creation` → 选项目 → 勾选已完成分析的录像 → 填游戏、内容类型、平台、目标秒数、目标与可选主题／排除 → **「生成三种模板方案」**。

可选：顶部「活动规则」粘贴或选本地 txt／md／html／截图／PDF（≤10MB）解析后「填入需求」（**Free 套餐不含**活动规则解析）。

### 会发生什么

- 离线模板生成最多三种方案（如按时间、钩子优先、倒序等），写出草稿与**缺口**；有缺口的方案不能渲染。
- 可按内容类型出现「推荐」蓝框；推荐来自已保存描述与规则，不是现场看懂画面。
- **内容模式诚实边界（与工作台方案卡／帮助同一句）：**「描述代理评分、非画面理解／未做人评／投放未验证」。评分与取材只用已保存文字／规则代理，不声称看懂画面；成品与攻略正确性未做人评；广告／买量不验证真实投放效果。工作台 `/creation` 页头、内容类型旁与推荐方案卡会重复这句，便于对照本手册。
- 若你过去常用某种结构做成片，通用方案可能按本机历史往前排，并写明「你常用的结构」；内容模式自带模板仍优先。

### 不会发生什么

- 不调用模型，不产生新分析费用，不改原分析目录。
- 不会把不足素材「复制凑数」成可渲染方案。
- 不会自动开始渲染。

### 常见问题

- **三个都不能用？** 看缺口提示：多选录像、降低目标秒数、或补齐必含主题的已保存文字依据。
- **活动规则解析失败？** 截图／PDF 靠本机 OCR，复杂排版可能漏项；以原文为准。Free 会提示套餐不含此功能。

## 7. 调整镜头、字幕、配乐、变速与转场

**Studio定时叠加（工作分支验证中）：** 打开 `/studio` 的“剪辑”，选可编辑方案后，在右侧检查器选“叠加”。输入文字点“添加文字”，或上传不超过8MiB的PNG；每层可设置成片中的开始/结束/淡入/淡出秒，以及位置和宽度百分比，列表从底层到顶层。“更新文字”重新生成对应字形；“上移一层／下移一层”调整遮挡关系。图层结束时停止显示，时间不跟随源镜头的变速。

预览按导出设置中的横屏/竖屏画布显示。越界时先按提示缩小图层或调整时间，再保存或导出。“保存版本”会保存图层；在素材页“我的作品 → 剪辑版本”可重新打开，删除最后一层后保存即可清空。上传或登记未完成时保存暂不可用。“撤销修改”恢复当前保存版本。该功能添加独立图层，不能抠除原录像里已经存在的logo；整批门禁前不代表已发布。

### 入口

选中可用方案后的 **「调整镜头」** 及同页「配乐与音量」等；改完必须 **「保存新剪辑版本」** 再生成视频。

### 会发生什么

- 可裁切入出点（按帧吸附）、上下移动、删除（至少留 1 镜）、手写字幕、配乐与原声音量、按原声能量压低配乐、逐镜 0.5x／1x／2x、交叉淡化等。
- 每次保存产生**新版本**；旧方案／旧成片／原片保留；可从历史打开祖先版本恢复。
- 可用已保存事件替换镜头（见页内说明）。
- 登记本地音乐（不下载、不上传）：

```powershell
./scripts/register-music.ps1 -InputPath <本地音频> -Title <曲名> -SourceDescription <来源说明> -LicenseStatus user_declared -LicenseEvidence <可选>
```

  声明≠权利已核实；`test_only` 不能当正式商用授权。

### 不会发生什么

- 不会偷偷加长源区间来「凑」慢放；慢放可以超过最初目标秒数，界面会显示差异，但不改 Brief。
- 手写字幕不修改原语音转录文件。

### 常见问题

- **交叉淡化保存失败？** 入场＋出场重叠帧之和必须小于该镜输出帧，且至少留 1 帧独占。
- **配乐被改镜头冲掉？** 设计上改镜头／字幕应保留配乐设置；若异常，从祖先版本恢复。

## 8. 生成成片（渲染）

### 入口

创作页明确选中可用方案（或剪辑版本）→ 选横／竖屏尺寸与字幕方式（不加／导出 SRT／烧入并导出 SRT）→ **「将所选方案生成视频」**。
开发批处理：`./scripts/render-creation.ps1 ...`（工作台渲染走套餐水印；开发者 CLI 是否加水印以当前产品决策为准，见任务清单 T15）。

### 会发生什么

- 本机 FFmpeg 按选定顺序裁剪拼接，写出 MP4；可选 `subtitles.srt`。
- **Free 套餐**：提交渲染时固化是否加水印；成片右上角烧入半透明 **「GamingCreator Free」**；收据记录水印，核验时比对；页面在成片旁和「套餐与用量」说明。之后改套餐**不会**改掉已生成片子上的水印记录。
- 创始人验证版／Creator／Pro：**不**加该水印。
- Free 另有每月成片次数上限（如 10 次，以页面为准）；计数含进行中与已完成的渲染任务。
- 完成后可播放、下载；刷新／重启可从历史打开，**不**自动重跑。

### 不会发生什么

- 不会覆盖已有输出目录；不会只靠改 JSON 路径去指向任意原片（源变动／回执不符会拒绝）。
- 不会把水印文案当成可执行的字幕特效语言（含花括号、反斜杠、换行等会拒）。
- 不代表创意质量或平台合规已通过。

### 常见问题

- **为什么有水印？** 当前选的是 Free；切到创始人／Creator／Pro 再**新**渲染才无此水印。
- **竖屏平台包能否裁掉水印？** 不能指望裁掉：包流程仍按实现保留／重烧策略，收据可含水印字段。
- **失败／中断？** 状态里说明原因；再次生成是一次新的显式任务。

## 9. 封面与文案

### 入口

成片完成后 **「封面与文案」**：用当前播放位置抓封面帧，编辑标题／简介／Tags，保存为独立版本。

### 会发生什么

- 得到可分别下载的 `cover.png`、`title.txt`、`description.txt`、`tags.json`、`publication.json`。
- 只抽已有视频帧，不重渲染、不扣模型费。

### 不会发生什么

- 不等于四平台正式发布包已齐。
- 文案模板未做人评。

### 常见问题

- **历史丢了？** 版本在任务历史里，可重开旧版续编。

## 10. 四平台本地预览包

### 入口

保存封面文案后，选择 B站／抖音／快手／小红书等本地配置 → 生成该平台预览包。

### 会发生什么

- 每次一个平台；可改尺寸、补边／裁切、本地文件大小／时长／文字／必需标签等**可编辑限值**。
- 完成后下载 `package.zip`（含 video／cover／title／description／tags／platform／validation 等），或分文件下载。
- 旧任务沿用当时配置；刷新不自动再编码。
- 若成片带 Free 水印，包侧核验会对照父成片水印字段；页面可提示「含 Free 水印」。

### 不会发生什么

- 这些限值**不是**已核官方规则；生成成功只表示文件已写出。
- **不会**自动联网发布；测试用途音乐等会挡住「发布资格」，但预览包仍可下载自查。
- Free 对「同一成片多个平台包」等能力可能不含（见套餐功能表）；页面会说明。

### 常见问题

- **validation 未通过？** 按本地限值改文案／时长／换图，或检查套餐功能闸。
- **资格未核实？** 平台规则、素材权利、人审未知时保持「未核实」是预期。

## 11. 团队审核与沙箱发布

### 入口

- **团队与审核**：按**当前项目**配置成员角色（owner／editor／reviewer／viewer）、品牌必须词／禁用词、「发布前必须审核」；操作人姓名为**自报**，不是登录账号。可导出该项目审核／团队变更的 JSON／CSV 审计（含自报标记）。
- 发布包下方：提交审核、通过／驳回（不能审自己的提交；驳回写原因；禁用词可挡通过）。
- **沙箱发布（本机模拟，不上传）**：通过后可点；页面演示已提交→处理中→已发布（模拟）。

### 会发生什么

- 审核与团队变更写入本机审计；历史可在页面展开。
- 旧版「全局一个团队」文件若仍在，可能只读回退；新保存写入**项目**团队文件。

### 不会发生什么

- 没有账号体系、跨设备同步、席位计费或真发布。
- 本地限值未通过或「仅供测试」音乐的包不能沙箱发布。
- 审核通过后若品牌词／审核员集合又变，可能需要重新审核（防过期通过）。

### 常见问题

- **导出的姓名是账号吗？** 不是；字段会标自报，避免误当成登录身份。
- **为什么不能发布？** 看阻断：限值、测试音乐、缺审核、套餐无沙箱权限等。

## 12. 套餐与用量（本地评估）

### 入口

创作页底部 **「套餐与用量」**。

### 会发生什么

| 套餐 | 要点（以页面与程序内套餐表为准） |
| --- | --- |
| 创始人验证版（默认） | 功能不限；不限成片次数与准备分钟；无 Free 水印 |
| Free | 功能闸更严；每月成片次数有上限（如 10）；准备分钟约 60；成片水印「GamingCreator Free」 |
| Creator | 含活动规则、多平台包、沙箱等；较高成片上限；无该水印 |
| Creator Pro | 再含专业时间线导出等；更高成片上限；无该水印 |

切换后**新**任务按新套餐执行；已生成成片的水印与历史收据不改写。

### 不会发生什么

- 不产生真实扣款、发票或云端订阅。
- 不把本地评估说成已开通的商业付费服务。

### 常见问题

- **只是想去水印？** 改到非 Free 后再渲染新成片。
- **用量不准？** 看本机账本与当月已接受的准备／渲染任务；不要随手改 JSON。

## 13. 相关能力速览（同页可达）

- **创作反馈**：只读统计本项目方案采用、常见修改、成片／发布包比例；不上传。裁剪多时新方案可能提示「你常裁短，已建议更短片段」并写入可复现字段，不会偷偷改时长而不记录。
- **游戏知识**：本机条目检索／手填／文件导入；「插入到旁白」前请人工核对。
- **导出时间线**：FCPXML／OTIO／Premiere XML；引用原片路径，换机需重链；Premiere 变速片段可能仍需手工确认；字幕／配乐／旁白不随时间线完整导出。
- **旁白**：本机试听与引用知识；以页面状态为准。

# 方案
./scripts/plan-creation.ps1 -Project <项目> -Run <Completed版本> -Brief ./creation-brief.example.json -OutputPath <创作目录> -Select hook-first
