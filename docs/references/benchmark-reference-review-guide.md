# 先看原片，登记人工参考区间

在分析或查看模型结果前，按事前查询观看原录像，记录真实动作和可用区间。这个本机页面省去手写参考事件JSON；保存后可继续标注，再导出给已有冻结入口使用。这里不显示模型描述，不分析、检索、上传或产生模型费用，也不会自动确认人工判断。

## 准备页面

先按[验收准备指南](./benchmark-preparation-guide.md)复制计划模板，填写本地录像、原录制组、开发／测试分区、是否看过模型结果，以及事前查询。尚未标注时，referenceEvents为空，人工确认false、版本null、填写人为空。不能从文件数量猜测独立会话，也不能把看过结果的开发录像当成新的独立测试。

在仓库根目录使用已经准备好的PowerShell 7：

```powershell
./scripts/prepare-benchmark-references.ps1 -InputPath artifacts/acceptance-plan.json -OutputDirectory artifacts/reference-review-001
```

打开生成的`artifacts/reference-review-001/review.html`。它是独立的本机文件页面，当前不从8765工作台菜单进入，不需要另起服务。保留整个生成目录，后续导入要用原页面包。相对录像路径以输入计划所在目录为起点；生成后保存实际绝对路径和录像身份。

## 登记和保存

1. 选择事前查询，观看原录像，找到确实符合需求且上下文完整的动作。
2. 使用“用当前位置标记起点／终点”，或者手填源时间秒，最多六位小数。播放器标记便于登记，不是逐帧裁切；保存前回看核对范围。
3. 填写真实事件名称、独立动作归组及“为什么这个区间可用”，点击“登记这个可用区间”。例如同一次闪避的几个可用区间用同一个事件名称；同一个动作即使使用不同事件名称，也应保持相同动作归组，不能多算独立事件。
4. 同一事件名称继续登记会追加不同区间，归组必须保持。区间写错可删除这个参考后重新登记，其他参考保留。切换查询时已登记参考保留，尚未登记的输入会清空。
5. 点击“保存当前标注记录”，保留下载的JSON。页面不会自动保存；关闭前保存。下次打开原页面，用“继续已有标注”选择记录，再继续核对。

只有人实际完成参考确认后，才填写人工参考版本、填写人，并勾选确认／复核。未完成时保留草稿；负例不登记可用事件，少例单独评估，主查询需要至少十个独立可用参考。工具记录声明，不能认证独立性、代替观看或自动打分。

非零源起点或音画起点不同的录像暂时禁用播放器自动取时，页面会提示手填规范源时间。不要直接把播放器显示当成源时间；转换依据见[媒体时间合同](./media-processing.md)。此类自动映射仍是TD006后续工作。

## 导出计划，再冻结

将下载记录放到本地，例如`artifacts/reference-record.json`，通过原页面包导入到一个新目录：

```powershell
./scripts/prepare-benchmark-references.ps1 -ReviewDirectory artifacts/reference-review-001 -RecordPath artifacts/reference-record.json -OutputDirectory artifacts/reference-plan-001
./scripts/prepare-benchmark.ps1 -InputPath artifacts/reference-plan-001/benchmark-plan.json -OutputDirectory artifacts/acceptance-freeze-001
```

导入重新核对原页面包、原录像SHA和时长，以及事前来源／录制组／分区／已看结果声明／查询。只允许修改人工参考及版本、填写人、确认和复核；来源或查询变化必须重新准备并如实披露，不能沿用旧标注包。

每次输出用新目录，不覆盖输入、录像、原页面包或已有输出。导出成功只得到待冻结的`benchmark-plan.json`，不会自动冻结。冻结后查看准备缺口，再按既有指南绑定已完成分析、运行检索、[回看固定候选并判分](./benchmark-candidate-review-guide.md)。

## 常见情况与验收边界

| 情况 | 处理 |
| --- | --- |
| 原片无法播放 | 检查原本地文件及浏览器编码支持；保留已填内容，核对后再登记，不能据此确认参考 |
| 时间倒置、越界或重复 | 修改区间后登记；程序不自动扩展区间 |
| 载入记录不属于原资料 | 当前标注保留；使用生成该记录的原页面包 |
| 载入时又编辑了内容 | 保留新编辑，重新选择记录后再载入 |
| 导入失败或输出已存在 | 保留原资料，核对来源与记录，并换新输出目录；中断目录不是完整交付 |

真实三段开发录像已验证公开入口、桌面／窄屏播放、程序示例记录保存重载及空参考冻结衔接；程序示例不是真实人工标注。F006仍需独立人评，各主查询固定十位至少70%有用，缺位和重复计零。使用本页、准备完成或安装包检查通过都不代表内容质量通过。
