# 从工作台完成验收流程

日常找素材、回看和选片不用填这套流程。它用于项目开发中的正式人工检索验收：分析前标原片里的正确事件，检索后判断固定候选是否可用；也可保存开发演练。工具齐全不等于真实标注已完成。当前所需人工事项及提醒时点见[人工待办](../exec-plans/human-inputs.md)，无需为了继续当前离线开发现在填完所有步骤。

打开本机工作台，点击左侧“验收流程”，或进入`http://127.0.0.1:8765/acceptance`。新建一个有名字的流程；以后从“已保存的流程”选择它，或保留地址中的编号。进度和每步资料保存在`artifacts/benchmark-workflows/<编号>/`，不依赖浏览器缓存。启动工作台不自动执行步骤。

1. **登记**：可以从空表单开始，或载入没有人工判断的旧计划／登记草稿。打开表单填写录像完整路径、录制归组、用途、是否看过结果和事前查询。未填齐先下载草稿；填齐导出待核对计划。已有人工参考的计划直接从第二步继续，登记入口不会清空判断。
2. **原片参考**：在流程里选择待核对计划，点击核对并打开标注页。原片通过本机工作台播放；明确记录真实动作和源时间区间，保存下载的标注记录。时钟特殊的录像只手填区间；自动取时仍保持原有资格限制。
3. **核对标注**：选择刚下载的记录，重新核对实际原片和原查询，保存待冻结计划。空参考和未确认状态可以练习流程，不会变成人工确认。
4. **冻结**：保存事前来源、查询、参考和实际原片身份。文件可冻结但独立准备仍可能不足；查看冻结资料中的准备缺项。后面已经生成资料时，前面的步骤不能改写；要更换来源／查询，请新建流程。
5. **关联分析**：选择或填写当前仓库的已有分析项目，明确开发练习或独立测试，点击“读取可关联的分析”。页面按冻结录像列出匹配的分析版本、模型和任务编号；逐段明确选择，再点击“关联已完成分析”。不会默认选择最新版本，未完成或时长不同的任务会说明原因并禁选；刷新后重新选用途和读取，可恢复上次已保存的明确选择。菜单只读保存的任务资料，实际关联时仍核对录像和证据；同源不同版本不能冒充独立录像。仍可展开“使用已有对应表（可选）”上传[准备指南](benchmark-preparation-guide.md)中的映射，例如`{"source-1":"已完成任务编号"}`。这一步不开始分析；没有Completed分析时先按已有分析流程处理。
6. **固定报告**：明确点击才按冻结查询搜索一次。可选词法、语义或混合；后两种使用已有本机语义模型。普通检索保存在原项目，报告保存此次十位与检索身份；没有人工判断时未验证，报告仍保留。已有报告生成后要改检索方式，须在候选评审开始前明确再生成，历史仍在。
7. **固定候选评审**：打开评审页按原排名回看，填写日期／填写人、判断、理由和对应的事前独立事件；下载保存。缺位与重复不补位，可用判断不能脱离原参考。表单不会代替人判分。
8. **原排名评分**：选择候选记录，核对后评分。它重读原报告和保存排名，不重新搜索；原费用未知仍未知。未验证或未达标时仍保存报告，流程页分别显示执行完成与质量结果。这里显示报告结论，不自动修改仓库F006验收状态。

表单在新标签页打开。**修改后须下载，再回流程页选择下载文件提交**；仅打开或填写表单没有自动保存。流程页会保存已提交的输入和结果，并在执行期间读进度。关闭／刷新页面不会重做步骤；重启后读取进度，以实际进程锁判断是否仍执行，旧“正在执行”记录不被当成活进程。已中断或失败时保留原目录，明确点击重试才创建新的尝试目录。

上传JSON只送到当前本机工作台，不发送外部服务。计划须使用原录像完整路径，页面无法取得下载文件原来的目录，不会猜相对路径。单次选择文件最多4MiB，计划及人工记录仍遵守各自原合同的更小限制；过大／错身份／重复字段／资料改变会拒绝。生成的文件按登记SHA读取；原片只按该步骤的来源身份与SHA提供，不能用任意路径打开服务器文件。

当前真实验证使用三段已经看过模型结果的开发录像，两个Atom片段同录制组、人工参考与候选判断均未确认。登记、播放、保存、恢复、冻结、关联和计分可用，不表示十个独立录制组或70%可用度已经达到。[原片指南](benchmark-reference-review-guide.md)与[候选评分指南](benchmark-candidate-review-guide.md)保留各自的细节和命令入口。
