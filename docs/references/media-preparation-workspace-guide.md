# 在工作台准备多段录像

先把一批录像抽帧、提取音轨并保存为素材任务，再另行安排分析。准备在本机进行，不需要API密钥，不运行视觉、语音或检索模型，也不上传画面或预留费用。准备成功的任务会显示“素材已保存，等待分析”，还不能搜索新录像内容。

## 新建准备批次

1. 打开本地工作台，点击左侧“准备多段录像”。
2. 填写仓库`artifacts/`内的目标项目，例如`artifacts/my-recordings`；目录可以尚未创建。
3. 每行填写一段本机录像路径，一次1–100段。同一路径只提交一次；中文和空格可以直接填写，也可以保留复制路径时两端的引号。
4. 选择准备方案，填写**以后每段录像分析的上限**。这只是保存给后续分析的配置，不是本次付款、整批总额度或启动分析的授权。即使准备成功，后续分析仍须单独启动。
5. 点击“开始本地准备”，逐项查看结果。存储或环境问题会停止批次；输入文件损坏、丢失等问题会标出该项并继续其他项。

网页中的相对录像路径以**仓库根目录**为起点，例如`GameVideos/session-001.mp4`。这与命令行JSON清单相对路径以清单文件夹为起点的规则不同。网页不接受网址或网络共享路径；已经分析过的源视频仍由原任务登记后读取。

“画面采样”沿用基础采样配置；“连续动作”与“细节动作”保存各自已有配置。准备不会评价动作或细节理解是否准确。高级设置中的每段处理期限用于本地准备；达到期限可在环境恢复后显式继续原批次。

## 停止、关闭和接续

关闭窗口、刷新或关闭浏览器页不会自动取消后台准备；重新打开同一目标项目并读取已保存批次，可以连接服务仍在执行的工作。想停止时点击“停止本次准备”，等待页面确认停止。当前项可能已保存，已完成材料会保留。

再次准备同一批次时，填写原目标项目、点击“读取已保存批次”，在对应批次点击继续。修复有问题的本地文件后也用这个入口。系统保持原任务编号、方案和原分析上限；在表单填写新的上限不会修改已冻结批次。已经准备好的素材先核验并复用，不再抽取；已进入模型分析的任务只报告状态。

服务停止后没有后台任务继续执行。页面会把磁盘批次标作保存的状态，不会把旧“处理中”当作当前正在工作；重新启动服务后须明确继续，读取历史不会自动执行。原数据库尚未创建前就中断的批次暂不能从页面接续，应保留批次资料并重新提交，详见TD013。

同一服务一次执行一个准备工作；其他项目或命令行写入仍受原项目锁约束。提交或读取失败时先查看提示和保存状态，页面不会自动重复提交。

## 查看和保存结果

完成后点击“打开素材任务”，查看每段录像保存的画面、音轨、配置与阶段。点击“下载这次准备结果”，保存批次号、任务编号、逐项结果和零模型／零新预留计数。这是准备回执，不是分析结果、人工质量评分或成片。

已有完成的分析仍可按[多录像搜索指南](./project-retrieval-guide.md)联合查找；新素材的分析入口见[使用手册](./user-manual.md)。命令行清单与同批次继续见[批量准备指南](./media-batch-preparation-guide.md)。
