# Sprint T26：时间线中文指令语料（P041）

**状态（2026-11-01）：已完成（规则语料＋拒绝用例扩充；无云端模型）。**

## 目标

扩充本机**规则解析**中文时间线指令的接受／拒绝语料与测试；听不懂整句仍拒绝，不引入未批准云端模型。

## 非目标

- 不接 GPT／云端 LLM／未批准 Provider
- 不开放式语义猜测；不把拒绝句改成「尽量理解」
- 不宣称覆盖全部口语

## 设计

### 语料原则

1. **接受**：与现有句式同义、可 fullmatch 到白名单规则的说法（含中文数字、礼貌前缀、多子句连接词）
2. **拒绝**：含否定／例外／未支持操作（合并／复制／倒放／静音／调色／云模型）、非法倍率、越界编号——整句 `CommandError`，原 clips 不变

### 小幅同义扩展（仍 fullmatch）

- 语速：`改回原速`／`恢复正常`；位置：`片头`／`片尾`
- `EXAMPLES` 字符串同步，拒绝提示可读
- `parser` 标记改为 `rule-v4-corpus`（行为兼容 + 语料扩充）

### 测试

- 新增接受语料 parametrize（删除／调速／移动／交换／裁切／转场／多子句）
- 新增拒绝语料（云模型话术、合并复制倒放、模糊评价、非法倍速等）
- 旧回归保持；不发明假时序
